Its live [map detail record 4001](https://www.spokaneriver.net/watertrail/park-details/?parkID=4001) publishes the exact shared coordinate, river mile 88.5, year-round season, and daylight hours. These sources verify the paddler access site and use limits, not a surveyed shoreline toe.
