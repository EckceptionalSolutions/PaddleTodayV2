# B121 — Cave Falls Campground Put-In, Fall River, Idaho

The suspicious put-in was reviewed against American Whitewater’s Cave Falls Run description and federal Caribou-Targhee campground material. American Whitewater names Cave Falls Campground as the route put-in. Federal material documents Cave Falls as a developed Fall River campground near the Yellowstone boundary, but campground access and shoreline use may be seasonal or site-specific.

The stored coordinate remains the best route anchor. It is 323 ft from the matched Fall River flowline and 255 ft from mapped water, so it is retained as a conditional campground/access-area anchor rather than moved to an inferred wet-toe point. Confirm current Forest Service status, parking, carry path, shoreline access, river level, and boundary restrictions before launching.
