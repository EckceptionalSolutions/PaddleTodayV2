# Logan Creek coordinate follow-up

Nebraska Game and Parks’ current public launch layer provides defensible points for Bancroft and Oakland. Both features are public, open, shore launches with sand/gravel substrate; each carries a steep-ramp/drop note. The stored points were replaced in the route access inventory and Oakland’s trip-detail take-out. The Logan Creek route remains withheld because the Pender access is identified schematically on the official trail map, but its exact current water entry remains unverified.

The raw query response, feature IDs, coordinate method, uncertainty, NHD distances, and source hashes are in [review.json](review.json). Run `node verify.mjs` from this directory to confirm the two agency features, coordinate copies, controls, and the Pender route hold.
