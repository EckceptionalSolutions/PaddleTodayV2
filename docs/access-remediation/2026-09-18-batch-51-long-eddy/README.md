# Long Eddy public launch — batch 51

Two Upper Delaware routes shared **41.823937, -75.112437** as the Long Eddy access. The point was **370 feet from matched hydrography** and **201 feet from mapped water**, so both occurrences were suspicious.

The current [NPS Long Eddy access page](https://www.nps.gov/places/long-eddy-river-access.htm) and its public-access dataset identify Long Eddy at **10 Ferry Street**, near river mile 315, as a New York DEC-managed non-motorized gravel launch with trailer parking. That same NPS dataset identifies the old coordinate as the separate **Kellams Bridge** site at river mile 312, marked **fishing-only with no boat ramp**. The [Delaware River Water Trail](https://delawareriverwatertrail.org/map_locations/long-eddy/) publishes **41.8497, -75.1352** for Long Eddy at river mile 315.6. Satellite imagery places that point in the Ferry Street / river-access corridor.

I moved both Long Eddy coordinates to the Water Trail point and recorded the official NPS mismatch so the fishing-only site is not reused as a launch. The corrected point now classifies **review** as an authoritative access-site anchor. It remains about **168 feet from mapped water**; the sources establish the public ramp site but do not survey its toe, so the exact waterline remains open.
