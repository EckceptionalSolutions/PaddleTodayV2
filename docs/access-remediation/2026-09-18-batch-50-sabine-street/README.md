# Sabine Street Access — batch 50

The Woodway-to-Sabine and Sabine-to-Allen's Landing routes share the Sabine Street coordinate **29.7622, -95.3736**. The audit put that point **329 feet from the matched Buffalo Bayou flowline** and **268 feet from mapped water**, so it classified both occurrences as suspicious.

The current [TPWD Buffalo Bayou Paddling Trail page](https://tpwd.texas.gov/boating/paddling-trails/gulf-coast/buffalo-bayou/) names **Sabine Street Access** as a public trail access point and publishes that exact coordinate. TPWD also describes the downstream Sabine-to-Allen's Landing trip as about one hour. I retained the exact state-published coordinate and added an authoritative access-site anchor for both routes. The endpoints now classify as **review** because TPWD's point verifies the public access site but does not identify a survey-grade water-entry toe.
