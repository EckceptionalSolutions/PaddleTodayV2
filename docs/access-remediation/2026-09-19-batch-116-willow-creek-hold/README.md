# B116 — Willow Creek Campground hold, Boise River, Idaho

The suspicious take-out on boise-river-troutdale-willow was investigated as a possible campground access. Federal recreation records establish the Willow Creek campground, but current access guidance reports no boat access at the campground. No Forest Service source reviewed identifies a lawful public landing, parking/carry route, or exact water-entry coordinate.

The route is withheld from public release pending Forest Service confirmation. The stored coordinate is unchanged. The full public audit removes this route from the public suspicious queue; the inventory audit retains the endpoint as suspicious for follow-up. The Troutdale put-in remains reviewed under its existing conditional access control.

After the hold, public audit totals are 2,046 ok, 3,925 review, 8 suspicious, 0 failure, 75 unknown. Inventory totals are 2,210 ok, 4,231 review, 63 suspicious, 51 failure, 86 unknown. The registry remains at 1,257 authoritative access matches and 0 conflicts.
