# Suspicious access-point review — batch 31

This batch freezes ten distinct sites from the full suspicious-endpoint queue. It is still in progress: five sites have documented decisions and five remain in the source/imagery pass. The original coordinates and route occurrences stay in [selection.json](selection.json); this folder records the evidence and decisions so the batch can resume without reselection.

The audit's `suspicious` label means the stored point is more than 300 feet from the matched river flowline. It is a research flag, not a finding that the place is invalid. Review the physical access once, including all route occurrences. Confirm the managing agency's access identity, the actual water entry, the correct named waterbody and the endpoint's route role. Use imagery to distinguish the landing from a park pin, address or parking area. Record uncertainty honestly; do not snap a pin to a river centerline. Follow the complete [access remediation runbook](../../access-point-remediation-runbook.md).
