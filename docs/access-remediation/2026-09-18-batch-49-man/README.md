# Man public access — batch 49

Both Guyandotte River routes shared an old Man endpoint at **37.731, -81.875**, about **376 feet from matched hydrography** and **282 feet from mapped water**. The old point was suspicious in both routes.

West Virginia's active [Fishing and Boating Access Sites GIS record](https://services.wvgis.wvu.edu/arcgis/rest/services/Applications/dnrRec_fishing/MapServer/2/query?where=OBJECTID%3D489&outFields=OBJECTID%2CSiteName%2CCounty%2CWaterbody%2CAccessType%2COwnership%2CActive%2CxLong%2CyLat&returnGeometry=true&outSR=4326&f=pjson) identifies ObjectID 489 as **Man**, Logan County, Guyandotte River, active, WVDNR Wildlife-owned, with **Carry Down** access at **37.7441, -81.887894**. That point is consistent with the shared Man stop between Water Trail Trips 9 and 10 and satellite imagery of the river-side access corridor.

I moved both route endpoints to the live GIS point and registered it as an authoritative access-site anchor. Targeted hydrography checks place the point **52.5 feet from the connected Guyandotte flowline and on mapped water**; both occurrences now classify as **review** because an access-site anchor does not establish the exact water-entry toe.

There is an unresolved source discrepancy: the 2024 [WVDNR District 5 guide](https://wvdnr.gov/wp-content/uploads/2024/02/Pub_D5_FishingGuide_DNR_WILD_digital_rspreads.pdf) gives the Man point a longitude of **-81.8979**, about 0.55 mile west of the active GIS point. The Water Trail's Map 3 describes a concrete ramp, while the current GIS lists Carry Down. The route now directs users to confirm the signed access, current launch arrangement, carry, parking, and entry on site. I did not treat imagery as proof of ramp type or public entry.
