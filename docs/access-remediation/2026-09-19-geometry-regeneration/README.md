# Geometry and served-catalog regeneration

Reviewed the 57 route holds whose reason required canonical route geometry or served-catalog regeneration. Review-mode generation produced geometry for all 57. Thirty-two routes were released after named/network geometry, endpoint-snap, and coordinate-audit checks. Twenty-five remain withheld because they still have a curated fallback, a geometry endpoint snap over 1,000 feet, a suspicious/unknown endpoint, or a separate access/legal question.

The public geometry manifest, route-scoped assets, state bundles, explore-map overview, access registry, and audit reports were regenerated. The withheld manifest now contains 161 routes.

See [review.json](./review.json) for route-level decisions and [selection.json](./selection.json) for the batch membership.
