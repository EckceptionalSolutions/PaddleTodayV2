# Editorial reference prospect brief — October 6, 2026

This is a small, route-led outreach shortlist based on current Search Console winners and public paddling resources. It is a research brief, not proof that any organization will link to PaddleToday. No outreach has been sent.

## Why these routes

The July 4–October 3 Search Console performance view showed the Little Miami Kelley–Milford page as the site's strongest route landing page, with the Milwaukee West Bend–Quaas Creek, Ouachita Remmel–Whitewater Park, and Namekagon Big Bend–Trego pages also among the leading route pages. The Search Console Links report currently shows 185 external links, all directed to the homepage (95) or privacy page (90); its four displayed linking sites account for those 185 links. This is a weak route-level reference signal in the report, not a complete backlink census: Google's documentation says the Links report shows a sample of links it has found over time, so the 20 route pages in its internal-link table should not be treated as a complete crawl graph. [Google Search Console Links report documentation](https://support.google.com/webmasters/answer/9049606?hl=en).

## Crawl and link evidence checked October 6

URL Inspection for the Allagash Falls–Twin Brook route, the Allagash river hub, and Maine's state directory returned **Discovered — currently not indexed**, with the sitemap index as the discovery source, **Referring page: None detected**, and **Last crawl: N/A**. Yet the current 200-response HTML contains ordinary links from the Maine directory to the Allagash hub and route, and from the hub to all four Allagash route pages. These samples show no broken live link path; they show that Google has not recorded a crawl for these URLs or their source pages. Do not infer that all route pages are orphaned from the Links report, which is a sample and is not real-time. The sitewide Page indexing report is still dated September 20, so current category totals are not available.

## Outreach principles and tailored drafts

Ask for a link only where the page directly helps that organization's paddlers. Do not offer payment, reciprocal links, or an endorsement. Be ready to correct route facts when an organization supplies better access or safety information.

These drafts are ready for human review, but have not been sent.
