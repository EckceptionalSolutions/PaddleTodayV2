## Virginia Smith River follow-up

Fresh official Smith River Blueway and Henry County sources reopened a route family that had previously been planning-only. The Blueway publishes a distinct 6.4-mile Philpott Dam Tailrace-to-Bassett section and a distinct 3.3-mile Great Road-to-Fieldale section, with public access addresses, Class I–III or Class I–II character, cold-water and release warnings, and the Philpott generation hotline. Henry County planning records supply the Philpott tailrace coordinate, while current tourism pages document the Bassett, Great Road, and Fieldale access facilities.

Both routes remain planning-only. The published 65–1,400 cfs value is a release context rather than a station-certified recreational threshold tied to USGS 02072500, so no score band is invented. The route records include nearby-basecamp camping classification, explicit dam/release/private-bank controls, route-specific access anchors, a rights-clean Smith River image fallback, and hard boundaries at Bassett and Fieldale.

The same current Blueway access list cleared five additional adjacent sections: Fieldale→Doe Run (approximately five miles, with American Whitewater reporting Class II features and a lake-like final mile), South Martinsville→Frith (1.6 miles, Class I–II), Frith→Smith River Sports Complex (3.0 miles, Class I–II), Sports Complex→Marrowbone (2.4 miles, Class I–III with named Eggleston Falls), and Marrowbone→Mitchell (3.4 miles, Class I–II). The records use official public endpoint addresses and access-area coordinates, direct Bassett gauge context, cold-water and Philpott-release controls, camping classifications, the rights-clean Smith River image, and explicit adjacent-segment deduplication. The Sports Complex reach is marked advanced with a scout/portage warning; Mitchell remains the hard downstream boundary because Morgan Ford is not an official access.

## North Carolina New River follow-up

The current NC State Parks New River canoe-access map cleared one additional section: Kings Creek Access→Alleghany Paddle-In Access (5 miles, 2.5 hours for a moderate paddler). Kings Creek is a public vehicle-access launch; Alleghany is a mapped paddle-in state-park campground with GPS 36.554608, -81.324092 and an explicitly locked gate/no-vehicle-access control. The record remains planning-only because the existing Jefferson station is a same-river proxy rather than a station-tied recreational threshold. The package includes endpoint camping reservations, overnight-vehicle and shuttle constraints, cold-water/wood safety controls, the existing rights-clean New River image, and explicit separation from the existing U.S. 221→Kings Creek route.

## Colorado Yampa River follow-up

Fresh current Colorado Parks and Wildlife guidance reopened the middle Yampa family. CPW names the public Hayden Pump Station, Yampa River State Park Headquarters, and State Wildlife Area (Dorsey) ramps, and explicitly breaks the corridor into a 13-mile Pump Station-to-Headquarters section and a 7-mile Headquarters-to-Dorsey section. CPW also documents the diversion before Headquarters, limited public land and utility-intake boundary, flow-dependent Class I–V character, State Wildlife Area licensing, campground reservations, and current low-water/closure checks. Exact access-area anchors are stored for the pump station, Headquarters, and Dorsey; Dorsey is cross-checked against the Water Quality Portal boat-launch record.

Both Yampa routes are published as planning-only. USGS 09244490 is direct same-river telemetry at the downstream Dorsey reach, but CPW’s seasonal streamflow ranges are not a station-certified recreational threshold. The records therefore preserve conservative flow-watch bands without making a score claim, include cold-water, diversion, private-property, small-lot, and high-flow controls, classify camping as a lawful Headquarters basecamp or endpoint campground, use a rights-cleared CC BY 4.0 Yampa State Park image, and keep the two CPW sections separate for deduplication.

Fresh CPW Craig-area guidance also cleared the next two named sections: Yampa Valley Golf Course→Loudy Simpson Park (3.5 miles) and Loudy Simpson→South Beach / Yampa Project Pump Station (5.5 miles). CPW documents the undeveloped joint-owned Golf Course launch, the developed county ramp at Loudy Simpson, South Beach’s west-lot launch and industrial intake restrictions, county/State Park camping permissions, and the flow-dependent Class I–V range. USGS 09247600 below Craig provides direct same-river telemetry near South Beach. Both records remain planning-only for the same threshold reason, use the rights-clean Yampa image, and are bounded as separate CPW Site 4–5 and Site 5–6 sections.

The next CPW block cleared two more routes: Duffy Mountain→Juniper Canyon (12 miles) and Juniper Canyon→Maybell Bridge (13 miles). CPW provides exact public ramp map anchors, primitive camping permits at Duffy, Juniper, and Maybell, and the high-consequence Juniper Class III–IV diversion warning with required portage planning for inexperienced/open-canoe crews. USGS 09251000 near Maybell is retained as direct same-river context, but the seasonal and class guidance still does not support a scored threshold. Both records are advanced planning routes with explicit private-land, rough-road, cold-water, rescue, and mandatory-take-out controls.

A consolidation group links the five adjacent records without overlapping their river miles; the existing Salem Rotary→Wasena card remains downstream and separate.

## Colorado Upper Colorado section follow-up

Current BLM recreation pages and the current Upper Colorado section guide cleared four additional distinct section records: Pumphouse→Radium (4.5 miles, Class II–III), Radium→Rancho Del Rio (6.5 miles, Class II–III), State Bridge→Two Bridges (4.7 miles, Class I–II), and Two Bridges→Catamount (10.1 miles, Class I–II). BLM currently documents Pumphouse, Radium, State Bridge, Two Bridges, and Catamount as river accesses with ramp, parking, restroom, fee, camping, or day-use details. The section records use current BLM recreation-site imagery, endpoint coordinates, direct same-river USGS 09058000 or 09060799 telemetry, and explicit private-access/day-use/camping boundaries.

All four records are scored because their gauges are direct Upper Colorado stations and their flow cues are tied to the existing route evidence: a conservative 900 cfs minimum for the Pumphouse/Radium block and the existing 700–9,000 cfs State Bridge/Catamount planning band for the downstream block. The records retain Class II–III or Class I–II moving-water, cold-water, wood, traffic, weather, ramp, parking, and mandatory-take-out controls. The shorter sections are kept as separate named endpoint options for trip planning and discovery; their duplicate-separation notes preserve the existing 15-mile Pumphouse→State Bridge and 16-mile State Bridge→Catamount macro routes rather than replacing them.
